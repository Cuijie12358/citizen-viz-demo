# 小红书一键发布指南

## 📌 概述

本工具集自动化生成小红书发布内容，包括：
- ✅ 文案（标题 + 正文 + 话题标签）
- ✅ 图片处理（3张截图自动裁剪成小红书尺寸 1080×1440）
- ✅ 自动登录 & 填写 & 发布（通过 Playwright）

## 🚀 快速开始（4 步）

### 第 1 步：导出浏览器 Cookie（一次性）

1. 打开浏览器，访问 **https://www.xiaohongshu.com** 并登录你的账号
2. 打开 DevTools：按 **F12** → 选择 **Application** 标签
3. 左侧菜单找 **Cookies** → 点击 **https://www.xiaohongshu.com**
4. **全选所有 Cookie**，复制，粘贴到文本编辑器

   **或者使用扩展：**
   - 安装 **EditThisCookie** 浏览器扩展
   - 访问 https://www.xiaohongshu.com （已登录）
   - 点击 EditThisCookie 图标 → **Export** → 复制 JSON

5. 在项目 `scripts/` 目录创建文件 `xhs_cookies.json`，粘贴 Cookie 内容
   ```
   [
     { "name": "web_session", "value": "...", ... },
     { "name": "x_bd_vtoken", "value": "...", ... },
     ...
   ]
   ```

### 第 2 步：生成小红书格式的图片

```bash
cd scripts/
npm install sharp  # 如果之前没装过
node process_images.js
```

✅ 生成 3 张图片到 `scripts/xhs_images/`：
- `01_visualization.png` — 数据可视化仪表盘
- `02_predictor.png` — 成功率预测工具
- `03_data-table.png` — 数据表格

### 第 3 步：保存为草稿（推荐先做这步）

```bash
node save_draft.js
```

脚本会：
1. 自动打开浏览器并登录
2. 打开小红书创作中心
3. **自动上传 3 张图片**
4. **自动填写标题、正文、话题标签**
5. **自动保存为草稿**
6. 浏览器停留在创作中心，**你可以继续编辑或预览**

✨ **优势：**
- 内容已经填好，可以随时调整
- 在小红书中预览最终效果
- 满意后再发布，不用重复上传
- 可以设定定时发布

### 第 4 步：发布（两种选择）

**方案 A（推荐）：在小红书中手动发布**
1. 草稿已保存，打开小红书创作中心
2. 在草稿箱中找到你的草稿
3. 继续编辑或直接点击"发布"

**方案 B：一键自动发布**
```bash
node publish_xhs.js
```

脚本会重复第 3 步的流程，但最后会停在发布页面等你手动点击"发布"按钮。

> ⚠️ **安全考虑**：最后的"发布"按钮需要手动确认，避免误操作

## 🐛 常见问题

### Q1: "找不到 xhs_cookies.json"
**A:** 你还没有创建 Cookie 文件。按照第 1 步操作。

### Q2: "找不到图片"
**A:** 你还没有运行 `process_images.js`。先运行这个脚本生成图片。

### Q3: 脚本能自动点击发布按钮吗？
**A:** 不能。为了防止意外，最后一步需要你手动确认和点击发布。这样安全且可控。

### Q4: Cookie 会过期吗？
**A:** 会。小红书 Cookie 一般有效期是几个月。如果脚本登录失败，重新导出 Cookie。

### Q5: 能修改上传的图片吗？
**A:** 可以。替换 `docs/images/` 目录下的 PNG 文件，然后重新运行 `process_images.js`。

### Q6: 已发布的内容能修改吗？
**A:** 不能。脚本只负责发布，已发布的内容需要在小红书 app 或网页手动编辑。

## 🔐 安全提示

⚠️ **关于 Cookie 文件：**
- `xhs_cookies.json` **包含你的登录凭证**，不要分享给他人
- 已在 `.gitignore` 中，**不会被 commit 到 git**
- 使用完后可以删除，下次再生成新的

⚠️ **关于自动化：**
- 脚本不能自动点击最终的发布按钮，保证你总能看到最终确认
- 脚本遵守小红书网页版的正常操作流程

## 📞 疑问

如果脚本无法正常工作：
1. 检查 Cookie 是否正确（从浏览器登录状态导出）
2. 检查图片是否生成成功（运行 `process_images.js`）
3. 尝试更新 Playwright：`npm install --save-dev playwright@latest`
4. 小红书可能更新了网页布局，联系开发者更新脚本
