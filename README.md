# 新加坡公民申请数据可视化

📊 基于 sgprapp.com 真实数据的交互式数据可视化项目

## 🎯 项目概述

本项目收集并分析了新加坡公民申请的真实数据，包括：
- **387 条去重后的申请记录**
- **12 个维度的数据提取**（年龄、性别、学历、收入、房产状况等）
- **10 个交互式图表**展示申请结果与各维度的关系
- **可搜索的数据表格**，按质量评分分类

## 📈 数据统计

|------|------|--------|
| 总记录数 | 387 | 100% |
| 申请通过 | 通过率 | 100% |
| 审批时长 | 平均处理 | 61% |
| 高质量数据 | >60% 字段提取 | 23 条 |

## 🔍 主要数据维度

- **结果分布**：通过 / 拒绝 / 等待 / 上诉中
- **时间周期**：审批时长分布
- **财务**：月收入 vs 申请结果
- **背景**：学历、年龄、在新年限、PR年限
- **家庭**：婚姻状态、子女数
- **其他**：性别、房产、行业
- **质量评分**：数据完整性评估（0-100%）

## 📝 数据说明

**数据来源**：sgprapp.com/citizen （新加坡公民申请论坛）

**更新频率**：手动爬虫（需手动运行 scraper.py）

**数据清洗**：
- 去重：保留每个用户的最新记录
- 归一化：统一日期格式、结果分类
- 验证：年龄、收入等数值范围检查

**隐私保护**：
- 不包含个人联系方式
- 用户名为论坛昵称
- 只包含公开申请信息

## 🔧 技术栈

- **前端**：Vanilla JavaScript + Chart.js 4.4
- **后端**：Python 3 (BeautifulSoup4 + Requests)
- **样式**：CSS3（深色主题）
- **部署**：GitHub Pages + Static HTML
